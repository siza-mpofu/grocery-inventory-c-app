# Project Documentation

This folder organises the documentation for the Grocery Shop Inventory Management System into three project phases:

- **[Conception](conception/README.md):** Initial requirements, planning, and system design.
- **[Development](development/README.md):** Implementation, code book, file format, testing, and Phase 2 deliverables.
- **[Finalization](finalization/README.md):** Final report, presentation, evaluation, and future improvements.

Each phase folder contains a brief README describing its purpose and the materials included.
